# Band 10 Companion

Нативный iOS-проект для **Xiaomi Smart Band 10 בלבד** (цель — конкретная модель пользователя).

## Текущий этап

Первый прототип: BLE-сканирование, подключение и инвентаризация GATT-сервисов/характеристик. Это диагностический этап, не полноценная синхронизация и не установка циферблатов.

## Технические факты

Открытый проект Freeband описывает для семейства Band 10 канал BLE V2:
- сервис FE95;
- notify characteristic 005E;
- write characteristic 005F;
- 16-байтовый auth key, который создаётся при первичном сопряжении в Mi Fitness и хранится в папке приложения в Files;
- после аутентификации — protobuf-сообщения в кадрах a5 a5, AES-128-CTR.

Важно: опубликованный README Freeband сообщает, что BLE V2 аутентификация проверена на Band 10 Pro; на обычном Band 10 её ещё нужно подтвердить на физическом устройстве. Установка циферблатов в Freeband не реализована. Поэтому мы не считаем эти функции уже готовыми.

## Сборка

Нужен Mac с Xcode и XcodeGen:

```bash
cd Band10Companion
brew install xcodegen
xcodegen generate
open Band10Companion.xcodeproj
```

В Xcode выберите iPhone, задайте свой Team в Signing & Capabilities и запустите приложение.

## Проверка на браслете

1. Не отвязывайте браслет и не сбрасывайте его.
2. Оставьте Mi Fitness установленным, но полностью закройте приложение перед тестом соединения.
3. Запустите сканирование и проверьте, появляется ли браслет.
4. Подключитесь и сохраните список GATT UUID.
5. Перед следующим этапом сверим результаты с протоколом и логами.

## Безопасность

Auth key — секрет, аналог пароля. Не публиковать его, не добавлять в Git и не присылать в чат. Следующий этап должен читать ключ локально через системный выбор папки и хранить его в Keychain.

## План

1. Подтвердить обнаружение и GATT на обычном Smart Band 10.
2. Реализовать безопасное локальное получение auth key и Keychain.
3. Реализовать BLE V2 handshake, шифрование и protobuf-команды по проверенным протокольным данным.
4. Изучить формат и протокол установки циферблатов отдельно.
5. Только после реальных тестов добавлять фитнес-данные и остальные функции.

Исходник не является IPA. Для сборки и подписи iOS-приложения требуется Xcode на Mac.
